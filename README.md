# FAQ Accordion Project

This project is a *FAQ Accordion* created as part of *Task 2* of the *Syntecxhub Frontend Development Internship*.

## 📌 Project Description
This FAQ Accordion allows users to click on a question to expand or collapse the answer.
Only one question opens at a time, keeping the interface clean and user-friendly.

## ✨ Features
- Accordion open/close functionality
- Smooth animation effects
- Responsive design
- Simple and clean UI

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
